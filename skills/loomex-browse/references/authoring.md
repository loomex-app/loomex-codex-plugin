Fresh-read the current draft and start `loomex_editor_start` with its revision and checksum; without a draft, use zero and the freshly read active published checksum. The hidden core graph owns proposal, typed clarification, review, feedback, acceptance and guarded saving. Follow that same execution with existing run and interaction tools. Do not create a definition and save directly to bypass the graph. After authoritative accepted draft saving, show one compact draft view and open its verified detailed frontend editor.
