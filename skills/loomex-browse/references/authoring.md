# Active-chat workflow editing

Use the single [authoring contract](../../loomex-create/references/authoring.md) for catalog lookup, bounded validation repair, fresh-revision editing, exact mutation reconciliation, and saved-draft readback. A browse-originated Edit with Codex click binds the displayed workflow and selected version as baseline context, asks for the desired change in the current chat, and edits the current draft after a fresh read. If no draft exists, begin from the freshly read selected published definition with expected version zero. Preserve every untouched field. After verified readback, show the compact saved draft and open its detailed Loomex frontend editor in the Codex side panel. Publishing, activation, and execution remain separate requested actions.
